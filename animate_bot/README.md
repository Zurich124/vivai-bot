# Animate Photo Bot — каркас

Telegram-бот на aiogram 3 для "оживления" фото. Готова вся Telegram-логика
(меню, правила, FSM-сценарий загрузки фото), источник анимации нужно
подключить самостоятельно.

## Структура

```
animate_bot/
├── bot/
│   ├── config.py          # токен, тексты интерфейса
│   ├── keyboards.py       # inline-кнопки
│   ├── storage.py         # SQLite: хранение согласия с правилами
│   ├── assets/
│   │   ├── preview.mp4    # видео-превью на /start (вы добавляете сами)
│   │   └── app/           # сюда кладёте файл своего приложения
│   ├── handlers/
│   │   ├── start.py       # /start, превью, принятие правил, главное меню
│   │   ├── info.py        # экраны "Правила" и "О сервисе"
│   │   └── animate.py     # кнопка "Оживить фото" → выдача файла приложения
│   ├── services/
│   │   └── animation.py   # опционально: серверная генерация (см. ниже)
│   └── main.py             # точка входа
├── requirements.txt
└── .env.example
```

## Запуск

```bash
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# впишите в .env токен от @BotFather

# aiogram сам подхватит переменные окружения, если экспортировать .env,
# либо добавьте в начало bot/main.py:
#   from dotenv import load_dotenv; load_dotenv()

python -m bot.main
```

## Куда подключать свой источник анимации

Кнопка «Оживить фото» сейчас настроена на выдачу вашего собственного
приложения (см. раздел ниже "Как добавить/обновить файл приложения") —
генерация происходит внутри самого приложения, не на сервере бота.

Если вместо этого захотите вернуть серверную генерацию прямо в боте —
модуль `bot/services/animation.py` уже готов для этого, реализуйте там
`animate_photo()`, а в `bot/handlers/animate.py` верните сценарий приёма
фото (было в предыдущей версии — просите фото, вызывайте `animate_photo`,
отправляйте результат).

## Как добавить/обновить файл приложения

1. Положите файл приложения (apk/exe/что угодно) в `bot/assets/app/`
2. Уберите из этой папки файл-заглушку `PUT_APP_FILE_HERE.txt`, если он там есть
3. В папке должен остаться ровно один файл — бот отправляет его при нажатии «Оживить фото»
4. Чтобы обновить версию — просто замените файл в этой папке на новый и перезапустите бота
   (`Ctrl+C`, затем снова `python -m bot.main`) — код менять не нужно

## Как добавить/обновить превью-видео на /start

1. Подготовьте видео (mp4, до 10-15 сек, до 20 МБ) и назовите его `preview.mp4`
2. Положите в `bot/assets/preview.mp4`
3. Подпись под видео — переменная `PREVIEW_CAPTION` в `bot/config.py`
4. Чтобы обновить — замените файл и перезапустите бота, код трогать не нужно

## Что можно донастроить под своё оформление

- Все тексты — в `bot/config.py` (приветствие, правила, подписи кнопок)
- Кнопки и их порядок — в `bot/keyboards.py`
- Логотип/аватар бота, описание, имя — через @BotFather
- При желании добавить баланс/платную генерацию — пригодится таблица
  `users` в `storage.py`, в неё легко добавить поле `credits`

## Важно про правила использования

В `TERMS_TEXT` уже заложен явный запрет на загрузку фото реальных людей
без согласия и на сексуализированный контент. Рекомендую не убирать
этот пункт и реально проверять жалобы пользователей (кнопка "Пожаловаться"
в Telegram, а также своя модерация при масштабировании).
